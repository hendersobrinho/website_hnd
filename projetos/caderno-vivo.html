Caderno Vivo

App local de organização de estudos com cronômetro por bloco, dashboard semanal, cronograma gerado por IA e exportação para calendário. Sem nuvem, sem conta, sem assinatura.

Resumo

Por que esse projeto foi criado

O Caderno Vivo surgiu de uma necessidade simples: ter um lugar centralizado para planejar blocos de estudo, acompanhar o que foi feito e registrar o que ficou pelo caminho. Ferramentas online resolvem parte do problema, mas sempre têm algo que não encaixa. Uma conta a mais para criar, um plano pago para liberar alguma função, uma interface pensada para outra finalidade.


A proposta foi montar algo que funciona sem depender de serviço externo: abre no navegador, roda na máquina, salva tudo em um banco local. O banco é um arquivo gerado automaticamente na raiz do projeto. Nada é enviado a lugar nenhum.


Do ponto de vista técnico, o projeto foi uma oportunidade real de trabalhar com ASP.NET Razor Pages, Entity Framework Core e SQLite em conjunto. A complexidade foi crescendo conforme as necessidades foram aparecendo no uso diário, e o resultado é um app que eu uso de verdade.

Intenção

Ter um painel centralizado para planejar, executar e revisar blocos de estudo sem precisar de nenhuma ferramenta online, conta ou assinatura.

O que organiza

Blocos de estudo com cronômetro, projetos com checklist e roadmap, matérias da faculdade, artigos em produção, lembretes e exportação para o calendário do celular.

Como foi construído

ASP.NET Core Razor Pages com .NET 10, Entity Framework Core 8 e SQLite. Frontend com Bootstrap 5 e Bootstrap Icons. Funciona em Linux, macOS e Windows.

O que tem dentro

O app cresceu em módulos conforme a necessidade foi aparecendo. Cada tela resolve uma parte do problema de organizar estudos de forma séria e contínua.

  • Hoje: a fila do dia com os blocos de estudo em ordem de horário. Cada bloco tem um cronômetro integrado com suporte a pausa, e o app dispara alertas no navegador cinco minutos antes de cada bloco começar.
  • Dashboard: painel semanal com gráfico de barras por dia, percentual de blocos concluídos e métricas de ritmo como blocos no prazo, antecipados, depois do prazo, hora extra e média real por bloco no histórico completo.
  • Linha do Tempo: navegação por data para revisar dias anteriores, ver o status de cada bloco e acompanhar os próximos dias planejados em uma linha só.
  • Projetos: cada projeto tem descrição, prazo, prioridade, status, checklist de itens e um roadmap com fases e marcos. Blocos de estudo podem ser criados diretamente de dentro do projeto e ficam vinculados a ele.
  • Faculdade: cadastro de matérias com carga horária, tarefas com prazo e prioridade, histórico de aulas, pendências e dúvidas por matéria, e plano da semana com seleção em massa de blocos para excluir ou reorganizar.
  • Cronograma: o app gera um prompt pronto para colar em qualquer IA. A IA devolve um JSON com o plano do período e o app importa todos os blocos de uma vez, ignorando duplicatas e criando matérias automaticamente pelo nome. Também é possível adicionar blocos manualmente sem passar pelo JSON.
  • Lembretes: lembretes avulsos ou vinculados a matéria, projeto ou artigo, com prazo, prioridade e opção de fixar no topo do dashboard.
  • Exportar: três formatos de saída. Markdown para colar em uma IA com contexto completo dos estudos. JSON para reimportar um plano atualizado. Arquivo .ics para o Google Calendar ou qualquer app de calendário, com alerta de 10 minutos antes de cada bloco.

Decisões técnicas

A escolha de Razor Pages foi prática. Para um app local sem API pública, o modelo de página por rota é mais direto do que separar backend e frontend. Cada funcionalidade fica concentrada em seu próprio módulo, o que facilitou crescer o projeto conforme as necessidades foram aparecendo.


O banco de dados é um arquivo SQLite gerado automaticamente na raiz do projeto. Sem configuração, sem servidor, sem variáveis de conexão para ajustar. Funciona igual em Linux, macOS e Windows. O caminho do arquivo pode ser sobrescrito por variável de ambiente quando necessário.


No Linux, o app pode ser instalado como serviço de usuário via systemd. O repositório já inclui o arquivo de serviço pronto para usar, então o app inicia automaticamente ao fazer login e fica disponível no navegador sem precisar rodar nenhum comando manualmente.
